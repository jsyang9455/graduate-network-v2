# 요구사항 정의서 — jjobb_v2

번호 체계: `REQ-영역-NNN`. 우선순위: **P0** 필수 / **P1** 고도화 / **P2** 조건부(게이트).
수용 기준은 [08-test-strategy.md](08-test-strategy.md)와 매핑한다.

## 1. 기능 요구사항

## 3. 역할별 핵심 유스케이스

- **학생/졸업생**: 이력서 작성·PDF, 공고 조회/지원, 추천, 견학 신청, 커뮤니티, 상담 예약
- **교사**: 상담일지·문서, 소속 학생 열람, 공고/견학 보조, 통계 읽기
- **학교관리자**: 소속 학교 회원·권한·공고·견학·커뮤니티 운영, 메시지(P2)
- **시스템관리자**: 학교 등록, 전역 권한, 워크넷 동기화, 통계 관리
- **기업**: 가입(승인 대기) → 프로필 → **학교 승인 후** 공고 등록, 지원자 열람·상태 변경, 이력서 읽기
