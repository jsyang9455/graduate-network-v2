# 비전 및 범위 — jjobb_v2

> 기준: 1차 소스 `graduate-network` (커밋 `7f331fc`) + 전주공업고등학교 「전북지역 졸업생 취업지원 플랫폼 고도화(2차) 구축 과업지시서」(2026.7.)
> 원문: [spec/고도화-과업지시서.txt](spec/고도화-과업지시서.txt)

## 1. 한 줄 비전

전북지역 **다수 학교**의 재학생·졸업생·교사·협력기업을 하나의 플랫폼에서 연결하되, **학교별 데이터 분리**와 **역할×메뉴 권한**을 전제로 취업지원 업무를 디지털화한다.

## 2. v1 현재 상태 (있는 것)

v1은 전주공업고 단일 학교 전제의 **HTML/CSS/JS + Node.js/Express + PostgreSQL + Docker/Nginx** 웹 플랫폼이다.

| 영역 | v1 구현 | 한계 |
|------|---------|------|
| 회원 | `student` / `graduate` / `teacher` / `company` / `admin` JWT 로그인 | `school_admin` 없음, `school_id` 없음, 소속은 문자열 `school_name` |
| 채용 | 공고 CRUD, 지원, 지원자 목록 | 워크넷 없음, 지원 상태 알림 없음, 이력서 PDF 첨부 미약 |
| 상담 | 예약(`counseling_sessions`) + 일지(`counseling_journals`) | PDF/DOCX 문서화 없음, 학교 범위 격리 없음 |
| 이력/경력 | `career.html` 등 | **LocalStorage 의존** (`career_*`, `schools`, `jobPostings` 폴백) |
| 커뮤니티 | `posts` + 댓글 + 좋아요 | 카테고리/태그/신고/익명/스크랩 미흡 |
| 견학/박람회 | `announcements` (industry-visit, job-fair, certification) | 정원·승인제·출결 전용 모듈 아님 |
| 알림 | in-app `notifications` 테이블 | SMS/알림톡 없음 |
| 권한 | `checkRole(user_type)` 단순 RBAC | 메뉴 매트릭스·학교 범위 가드 없음 |
| 배포 | Docker Compose, AWS EC2 가이드 | 멀티테넌시·백업·감사로그 미흡 |

## 3. v2가 닫아야 할 갭 (과업지시서 배경)

1. **단일 학교 한계** → 멀티스쿨 + `school_id` 격리
2. **문서 산출 부재** → 이력서 PDF, 상담일지 PDF/DOCX
3. **실시간 알림 부재** → 알림톡/SMS (학교 유료 계정 등록 시)
4. **채용정보 수기 등록** → 워크넷(고용24) OpenAPI 수집 (학교 인증키 제공 시)
5. **맞춤 추천 부재** → 공고–이력 연관성 추천
6. **LocalStorage 의존** → 서버 API + PostgreSQL 전면화

## 4. 목표 (사업 목적)

- 전북 다수 학교·교사·학생을 한 플랫폼에서 운영, 학교별 데이터 분리
- 역할·소속 학교·메뉴 단위 접근 통제
- 이력서·상담 문서 자동화, 알림, 워크넷 연동
- 맞춤 취업 추천으로 매칭 효율 제고
- 서버·DB 기반 다중 사용자 안정성
- PC/모바일 반응형, 개인정보보호 준수

## 5. In Scope (이번 v2 구축)

| ID | 범위 | 비고 |
|----|------|------|
| IN-01 | 멀티스쿨, 학과/반, 학교관리자(부장교사) | 필수 |
| IN-02 | 역할 6종 + 메뉴×권한 매트릭스 + 감사 로그 | 필수. 화면·API 동일 정책 |
| IN-03 | LocalStorage → PostgreSQL/API 전환 | 필수. 공통 기반 |
| IN-04 | 단계형 이력서 + 한글 폰트 임베드 PDF | 필수 |
| IN-05 | 상담일지 고도화 + PDF/DOCX | 필수 |
| IN-06 | 자체 공고 + 지원 워크플로우 고도화 | 필수 |
| IN-07 | 워크넷 채용/행사 수집·통합 목록 | **학교 인증키 제공 시** |
| IN-08 | 취업 추천 (설명가능형 1차) | 필수 |
| IN-09 | 견학 공고·신청·정원/승인·출결 | 필수 |
| IN-10 | 선배 취업 커뮤니티 고도화 | 필수 |
| IN-11 | 파일 스토리지(S3 등) + 문서/첨부 메타만 DB | 필수 |
| IN-12 | 공통 모듈: 권한 엔진, 문서생성, 알림, 추천, node-cron | 필수 |
| IN-13 | HTTPS, bcrypt, 개인정보 AES-256, 백업, 처리방침 | 필수 |
| IN-14 | SMS/알림톡 발송 | **학교 유료 계정 등록 시에만**. 미등록 시 제외 |

## 6. Out of Scope (이번 구축에서 하지 않음)

| ID | 제외 | 이유 |
|----|------|------|
| OUT-01 | React/Next 전면 재작성 | 과업지시서가 기존 HTML/CSS/JS 계승을 명시 |
| OUT-02 | 학습형 ML 추천 모델 | 1차는 설명가능형(규칙+TF-IDF). 피드백 수집만 |
| OUT-03 | 네이티브 앱 | 반응형 웹만 |
| OUT-04 | 워크넷 연동 | 학교 인증키 미제공 시 진행 불가 (스텁·설정 화면만) |
| OUT-05 | SMS/알림톡 실발송 | 유료 계정 미등록 시 제외 (인앱 알림·콘솔 로그만) |
| OUT-06 | 타 시도 전국 확장 | 전북지역 학교 |
| OUT-07 | 콘텐츠 실데이터 대량 등록 | 학교는 관리자 화면으로 직접 등록 |
| OUT-08 | 무상 하자보수 이후 기능 추가 | 별도 유지보수 계약 |

## 7. 조건부 과업 (게이트)

착수 시 학교에서 확인해야 할 제공물:

1. **워크넷(고용24) OpenAPI 인증키** — 없으면 IN-07 보류
2. **SMS/알림톡 유료 발송 계정** (카카오 채널, 발신번호, 대행 계약) — 없으면 IN-14 제외

두 게이트 상태는 [STATUS.md](STATUS.md)의 `Gates` 섹션에 기록한다.

## 8. 성공 기준 (Phase 0 이후 구현 에이전트가 추적)

- 학교 A의 교사가 학교 B 학생·공고·상담을 API/화면에서 볼 수 없다.
- 역할별 메뉴가 권한 매트릭스와 일치한다.
- 이력서 PDF·상담 문서가 한글 깨짐 없이 다운로드된다.
- 경력/학교코드/게시 폴백이 LocalStorage에 의존하지 않는다.
- 권한 변경·개인정보 조회가 `audit_logs`에 남는다.
